Optical motion capture → musculoskeletal model

Mocap to MyoFullBody

Turns OptiTrack Motive recordings into motions of MyoFullBody, a 416-muscle MuJoCo model: reads raw .tak files without Motive, cleans the marker labels, calibrates each subject on a static standing trial, solves inverse kinematics, and checks the result against independent references. Built for a box-lifting study; the stages are meant to carry over to other marker datasets.

HandbookEvery stage, how it was checked, what the checks found, and the calibration fix. Motion viewerOpen an exported clip in the browser: bones, muscles, markers coloured by fit error, objects, joint angles. SourceCode, model files and the README on GitHub.

Pipeline

raw .tak→marker conditioning→static-trial calibration→least-squares IK→reference + QA→motion clips

Case study in numbers

  • 22 trials, 11 subjects; the take reader matches Motive's own exports to 0.005 mm.
  • Marker residual median 7.5–12.3 mm per trial; OpenSim IK on the same data gave about 21 mm.
  • The static-trial calibration removes an 8–10° knee offset found against Xsens.
  • About an hour of CPU time for the whole dataset, no manual labelling.

No subject data is published here: the viewer opens files from your own disk and uploads nothing.
