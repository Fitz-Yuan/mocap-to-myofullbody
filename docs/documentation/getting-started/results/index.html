Reading the results#

All results go into the folder the dataset profile names as root (M2M_ROOT).

Start with the report#

ik/report.md has one line per trial: PASS, WARN or FAIL, the values behind the grade and the reasons. Quality checks and the report explains every check and its limits. A WARN is worth a look in the viewer; a FAIL says which part of the trial not to use (a lost limb, a bad marker fit, a crouched standing posture that points to the calibration).

The files#

File

Contents

ik/<trial>.npz

qpos [frames, nq] the model’s joint coordinates, joint_names, marker_err [frames, markers] each marker’s distance to the model (m; NaN where missing), rejected (samples set aside as mislabelled), rate, scale

ik/<subject>_offsets.npz

the calibration: where each marker sits on the model

kin/<trial>.npz

joint moments and forces (hip_r_ext, knee_l_ext, ankle_r_plantar, L5S1_ext, L5S1_compression, …; N m and N), the ground reaction and its centre of pressure, per foot foot_force and where it came from (foot_source: 1 force plate, 0 estimated), frames whose loads are not determined (uncertain)

kin/muscles/<trial>.npz

with --muscles: each muscle’s activation and force, the reserve torques

Load them with numpy:

import numpy as np
K = np.load("ik/S01_walk01.npz")
names = list(K["joint_names"])
knee = K["qpos"][:, 7 + names.index("knee_angle_r") - 1]   # the root (a free joint) takes qpos[0:7]

Files and formats lists every array.

Watch a trial#

mocap2myo export viewer viewer/ S01_walk01 --dataset my_study.toml

writes the trial’s clip (viewer/S01_walk01.elvw) and the model into viewer/. Drop the clip on the viewer; it loads the eight built-in models itself (for another model, drop its *_model.elvw too). Without trial names, every solved trial is exported.

Gap-filled markers for other software#

mocap2myo export c3d filled_c3d/ --dataset my_study.toml

writes each trial’s markers as C3D with the gaps filled: from three neighbouring markers where they are seen (a rigid body fill), else from the subject’s model in the IK pose. Residual 0 marks a measured sample, 1 a filled one. Gap filling explains the method and Gap filling against established methods its accuracy.

Motion for training#

mocap2myo export motion clips/ --dataset my_study.toml --fps 100

writes every trial’s motion as clips at a fixed rate with the feet on the floor, for imitation learning or animation: each tracked body’s position and velocity, the root’s position and orientation, the joint angles, and index.json (where each clip comes from, with the trial’s QA numbers). A trial is cut where the IK lost a limb for 0.2 s or longer; clips shorter than 1 s (--min-s) are left out. Files and formats lists the arrays.
