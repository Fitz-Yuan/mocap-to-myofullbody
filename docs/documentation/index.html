Mocap to MSK#

Motion capture in, musculoskeletal motion and joint loads out.

Mocap to MSK turns optical motion capture (OptiTrack .tak or Motive’s CSV export, Qualisys TSV, C3D, TRC, AddBiomechanics .b3d) into the motion and joint loads of a MuJoCo musculoskeletal model: MyoFullBody by default, or MS-Human-700, MASS, Rajagopal 2016, Lai–Uhlrich 2022, Gait2354 and MyoLeg. It reads the raw recordings itself, calibrates each subject, solves the inverse kinematics frame by frame, computes the joint loads by inverse dynamics (and, optionally, muscle forces), and grades every trial so you can see how far to trust it. Every step was checked against an independent reference: Vicon Plug-in-Gait, AddBiomechanics, OpenSim, Xsens inertial capture and force plates.

Quick start#

git clone https://github.com/Fitz-Yuan/mocap-to-myofullbody
cd mocap-to-myofullbody
python -m venv .venv && source .venv/bin/activate
pip install -e ".[c3d,tak]"
mocap2myo demo

The demo downloads one public walking trial (about 0.4 MB) and runs every step on it in about a minute. Then process your own data.
